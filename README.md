# data-pipeline-workflows

Architecture-first workflows for data engineers. Cloud-agnostic.

## Skills

| Skill | Use it to |
|---|---|
| `design-pipeline` | Get 3 architectures (simple -> advanced) with diagrams and trade-offs |
| `review-dbt-model` | Review materialization, incremental logic, tests, cost |
| `review-airflow-dag` | Review idempotency, retries, scheduling, task design |
| `optimize-spark-sql` | Tune Spark/SQL: volume reduction, pushdown, parallelism, caching |

## Conventions

Answers lead with the conclusion, then detail. Code uses clear names and comments. Comparisons include trade-offs and when to use each.
